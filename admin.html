/v1/chat/completions 走哪个上游，只列 openai 协议的 profile。
路由条目未显式声明 upstream 时走哪个 profile。
上游 profile 每个 profile 是一份独立上游（地址 + 单一协议 + 密钥 + 超时）。路由与 proxy 选择器按名字引用。标注「内置」的两个来自上面的 [upstream] 地址，同名新增即覆盖它们。
新增后须填写密钥并选「设置」；删除仍被路由引用的 profile 会被拒绝。
模型路由表 别名即 Claude Code 请求的模型名；supports_image 表示该上游模型原生支持图片，跳过 VLM 描述。
经过默认网关与内置兜底之后，每个别名实际走哪个模型。这里的内容不会被保存。
保存会先备份为 <配置文件>.bak.<时间戳>，再原子写入并立即生效（端口变更除外，需重启服务）。
